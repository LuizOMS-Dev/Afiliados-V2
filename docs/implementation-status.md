# Estado da versão V2

O ZIP original foi importado para o repositório `LuizOMS-Dev/Afiliados-V2`.

A preparação inclui instalação pelo lockfile, ambiente de exemplo, Dockerfile com healthcheck, Compose com PostgreSQL e volumes persistentes, documentação e CI para testes e integração da imagem Docker com PostgreSQL.

O código existente oferece catálogo, upload, login administrativo, identidade visual, acompanhamento de cliques, conexões WAHA, grupos, programação e envio manual/automático. Em banco novo, os controles de envio começam desabilitados e pausados.

A entrega atual limita-se ao GitHub por solicitação do usuário. A implantação em hospedagem, domínio HTTPS, segredos reais, backups e conexão WhatsApp serão configurados em etapa posterior. Referências a serviços anteriormente criados no ZIP descreviam outro ambiente e não comprovam uma implantação desta versão.
